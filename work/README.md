# Course work

Everything you produce goes here, one folder per course:

```
work/
  log/              weekly logs (YYYY-Www.md) and review-week retrospectives
  M101/
    notes/          week-01.md … one page per week (templates/notes.md)
    build/          the course build, with a README (templates/course-readme.md)
    memo.md         the business memo (templates/business-memo.md)
```

Large builds can live in their own repository; link them from `progress/transcript.csv`.
