**Resources:** MIT Missing Semester (free); GitHub Actions docs; pytest docs

## Final deliverables

- **Exam (50%, pass at 70%):** Practical: from a clean clone, fix a seeded bug and get CI green within 60 minutes
- **Build (30%):** Data pipeline with tests, linting and a CI/CD workflow on GitHub Actions — in `work/C102/build/`
- **Business memo (20%):** Cost of defects and release risk: the business case for CI/CD on a client project — in `work/C102/memo.md`

## Fast track

Confident in this material? Add `C102` to `fast_track` in plan/config.yaml. The course then takes 3 weeks instead of 9: a timed diagnostic using the assessment above, the build, then the memo. Below 70% on the diagnostic, switch to the full course. See [the fast-track guide](../../fast-track.md).

## Week by week

| Week | Plan week | Learn | Apply |
| --- | --- | --- | --- |
| 1 | [4](../../weeks/year-1.md#week-4) | Shell, scripting and command-line tooling | Automate a local data task end to end with a bash script |

Each study week: work the reading or lectures, then the problems, and keep one page of notes in `work/C102/notes/week-NN.md`. Commit the apply task to `work/C102/`.
