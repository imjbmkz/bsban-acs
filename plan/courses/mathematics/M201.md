- **Business memo (20%):** Lease vs buy for a server or vehicle, using present value — in `work/M201/memo.md`

## Fast track

Confident in this material? Add `M201` to `fast_track` in plan/config.yaml. The course then takes 3 weeks instead of 9: a timed diagnostic using the assessment above, the build, then the memo. Below 70% on the diagnostic, switch to the full course. See [the fast-track guide](../../fast-track.md).

Caution: this is part of the math and statistics core that master's admissions check first. The guide recommends taking it in full; its timed final is your proof.

## Week by week

| Week | Plan week | Learn | Apply |

| 1 | [41](../../weeks/year-1.md#week-41) | Integration by parts | Compute expected values of continuous distributions by integration |
