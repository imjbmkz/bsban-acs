# Level 1 — Foundations

Level 1 rebuilds math from precalculus to first-semester calculus and proofs, while two of the three
CS courses are test-outs that formalize what is already done at work.

| Code | Course | Prereq | Theory | Practice build | Business application | Main resource |
| --- | --- | --- | --- | --- | --- | --- |
| M101 | Precalculus & Mathematical Reasoning | – | Functions, logs, exponentials, trig, sequences | Plot and fit growth curves in NumPy | Compound growth of revenue, interest and churn | OpenStax *Precalculus*; Khan Academy |
| M102 | Calculus I | M101 | Limits, derivatives, integrals, optimization | Code numerical derivatives and integrals from scratch | Marginal cost/revenue; profit-maximizing price | MIT OCW 18.01SC; OpenStax *Calculus Vol. 1* |
| M103 | Discrete Math & Proofs | M101 | Logic, sets, induction, combinatorics, graphs | Graph algorithms on a lineage or dependency graph | Counting scenarios for capacity planning | *Book of Proof* (Hammack); MIT 6.042J |
| S101 | Introduction to Statistics & Data Analysis | – | Distributions, sampling, CIs, hypothesis tests | EDA + inference report on a public dataset | Is the sales uplift real or noise? | *OpenIntro Statistics* (free) |
| C101 | Programming Fundamentals (Python) — *test-out* | – | Types, functions, OOP, complexity basics | Clean, typed, tested Python package | Reusable internal tool | CS50P final project as proof |
| C102 | Software Engineering Practices | C101 | Version control, testing, CI/CD, code review | GitHub Actions pipeline with tests and linting for a data project | Cost of defects; release risk | MIT *Missing Semester*; GitHub Actions docs |
| C103 | SQL & Dimensional Data Modeling — *test-out* | – | Relational model, normalization, star schemas | dbt project with tests and docs on a public dataset | KPI layer a finance team can trust | Kimball *Data Warehouse Toolkit*; dbt Learn |
| B101 | Principles of Microeconomics | – | Supply/demand, elasticity, market structures, game theory | Estimate price elasticity from data | Pricing recommendation memo | CORE Econ *The Economy* (free); MIT 14.01 |
| B102 | Financial Accounting | – | Three statements, accruals, ratios | Parse filings into a ratio dashboard | Read a company's health in 10 minutes | OpenStax *Principles of Accounting Vol. 1* |
| B103 | Structured Problem Solving & Business Communication | – | Issue trees, hypothesis-driven work, pyramid principle | Rewrite one past work project as a consulting deck | Executive summary that gets a decision | Minto *The Pyramid Principle*; *Bulletproof Problem Solving* |

**Level 1 exit check:** score at least 70% on a timed Calculus I final (e.g., an MIT OCW exam) and
finish the C102 and C103 builds, which also close the CI/CD and dbt gaps.
